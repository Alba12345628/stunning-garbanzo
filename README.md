# MMR Tracker

Рейтинговый трекер практики в стиле доты. **Каждый навык — независимый
профиль**: свой MMR, свой ранг со звёздами, своя серия побед, свой дневной кап
и свои пропуски. Гармошка на x2.0 не даёт горловому пению вообще ничего — они
не делят ни очки, ни лимит минут, ни календарь пропусков.

Чистая статика, без сборки и без бэкенда. Прогресс лежит в `localStorage`
браузера — на каждом устройстве свой.

```
index.html    разметка
styles.css    тёмная тема
app.js        вся логика: MMR, звёзды, серии, пропуски — всё per skill
```

## Правила (применяются к каждому навыку отдельно)

| Правило | Значение |
|---|---|
| Базовый фарм | 1 мин = **+2,5 MMR** |
| Серия 3+ дня | множитель **x1.5** |
| Серия 7+ дней | множитель **x2.0** |
| Кап анти-тильта | **20 мин/день на этот навык**, минуты сверх не дают MMR |
| Пропущенный день | **−100 MMR** этому навыку, его серия обнуляется |

Множитель считается по серии **включая сегодняшний день**: третий день подряд
уже фармится с x1.5. MMR не уходит в минус — нижняя граница 0.

## Ранги и звёзды

Каждый ранг делится на 5 звёзд, у ТИТАНа звёзд нет. Считает хелпер
`getRankAndStars(mmr)` в [`app.js`](app.js) — он ничего не знает про навыки,
просто переводит число MMR в ранг+звезду+тайтл, а каждая карточка вызывает его
для *своего* `skill.mmr`.

| Ранг | MMR | Шаг звезды |
|---|---|---|
| Рекрут · Herald | 0 – 750 | 150 |
| Страж · Guardian | 751 – 1500 | 150 |
| Рыцарь · Crusader | 1501 – 2300 | 160 |
| Герой · Archon | 2301 – 3100 | 160 |
| Легенда · Legend | 3101 – 3900 | 160 |
| Властелин · Ancient | 3901 – 4700 | 160 |
| Дивайн · Divine | 4701 – 5400 | 140 |
| ТИТАН · Immortal | 5401+ | — |

Отсчёт внутри ранга идёт от значения **перед** его началом, поэтому границы
совпадают с таблицей: Страж 1 = 751–900, Рыцарь 1 = 1501–1660,
Дивайн 1 = 4701–4840. Рекрут начинается с нуля, и его первая звезда на единицу
шире (0–150).

> В исходной спеке Страж начинался с 760, из-за чего диапазон **751–759**
> не принадлежал ни одному рангу. Здесь Страж начинается с 751.

## Навыки — независимые профили

Из коробки — губная гармошка и горловое пение. Свои добавляются прямо в
интерфейсе: значок (любой эмодзи) + название, до 10 активных одновременно.
У каждого навыка своя карточка со всем набором: ранг, звёзды, MMR, прогресс до
следующей звезды, серия, сегодняшний кап, форма ввода и кнопка «Пропустил
день».

Пропуск по одному навыку **не блокирует** и не штрафует остальные — если
гармошку фармишь каждый день, а горловое забросил на неделю, заблокируется и
оштрафуется только карточка горлового пения.

Убранный навык (крестик на карточке) не стирает его MMR и историю — они
остаются в журнале и на теплокарте. Если добавить навык с тем же названием
обратно — он вернётся со всей накопленной статистикой.

> **Миграция со старой версии.** До этого обновления MMR/ранг/серия были
> общими на всё приложение. Честно разделить уже накопленный общий счёт по
> навыкам невозможно — не сохранялось, кто из них сколько заработал. При
> первом открытии обновлённой версии рейтинг каждого навыка стартует заново
> с нуля; сама история дней и график активности никуда не делись.

## Наиграно часов

Плашка в шапке суммирует **все** минуты по **всем** навыкам за всё время,
включая срезанные капом. Это счётчик вложенного времени в целом, а не очков
конкретного навыка.

## График активности

Теплокарта в стиле GitHub — общая, по сумме минут всех навыков за день (это
про «занимался ли я вообще», а не про чей-то конкретный ранг). 7 строк — дни
недели, колонки — недели. Переключатель периода `All` / `30d` / `7d`, выбор
запоминается. Заливка:

| Минут (сумма по навыкам) | Цвет |
|---|---|
| 0 | нейтральный фон |
| 1–10 | тёмно-синий |
| 11–20 | средний |
| 21–30 | яркий |
| 31–40+ | максимально яркий |

Принятый пропуск — красная клетка с `✕`, обнаруженный но не принятый —
красный пунктир. В тултипе дата, суммарное время и разбивка по каждому навыку.

## Пропуски

На каждый навык работают два независимых механизма, и они не штрафуют дважды.

**Автоматически.** Приложение сверяет календарь этого навыка: если между
последним засчитанным днём и вчера есть дыры, его карточка показывает красное
предупреждение и **блокирует фарм именно по нему**, пока поражение не принято
(всё сразу или по одному дню). Сегодняшний день пропуском не считается, пока
не закончился.

**Вручную.** Кнопка «Пропустил день» внутри карточки навыка. Если по нему уже
найдена дыра — кнопка закрывает самую старую. Если дыр нет — оформляет
добровольный абандон на сегодня. В обоих случаях −100 MMR этому навыку и его
серия в ноль.

## Настройка

Всё, что стоит трогать, лежит в начале [`app.js`](app.js):

```js
const MMR_PER_MINUTE  = 2.5;
const DAILY_CAP       = 20;     // минут в день на КАЖДЫЙ навык
const ABANDON_PENALTY = 100;
const STREAK_TIERS    = [ { days: 7, mult: 2.0 }, { days: 3, mult: 1.5 } ];
const HEAT_LEVELS     = [ /* пороги заливки теплокарты */ ];
```

## Локальный запуск

Достаточно открыть `index.html` двойным кликом. Если браузер ограничивает
`localStorage` на `file://`, подними любой статический сервер:

```bash
npx serve .
```

## Деплой на Vercel

Проект — голая статика, никаких настроек не нужно. Сначала один раз
авторизоваться:

```bash
npx vercel login
```

Потом из этой папки:

```bash
npx vercel --prod
```

На вопросы про build command и output directory жми Enter — статика
раздаётся из корня как есть.

Через веб-интерфейс: залей папку в репозиторий на GitHub, в Vercel нажми
**Add New → Project**, выбери репозиторий. Framework Preset определится как
**Other**, Build Command и Output Directory оставь пустыми.
